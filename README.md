o objetivo do FITSTEP é auxiliar o usuário a controlar e acompanhar suas atividades físicas de forma simples. Utilizando recursos do smartphone, como sensores de movimento, conexão Bluetooth e integração com outros aplicativos. O projeto busca reunir informações como quantidade de passos, distância percorrida, calorias gastas e tempo de treino em um único lugar.
